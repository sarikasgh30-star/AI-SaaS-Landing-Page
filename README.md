# AI SaaS Landing Page

A modern and responsive AI SaaS landing page built using **HTML**, **CSS**, and **JavaScript**. This project showcases a professional SaaS website design with sections for features, pricing, testimonials, and call-to-action buttons.

## 🚀 Features

* Responsive design for all devices
* Modern UI/UX
* Hero section with CTA buttons
* Features section
* Pricing plans
* Customer testimonials
* FAQ section
* Contact section
* Smooth scrolling navigation
* Clean and organized code

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
